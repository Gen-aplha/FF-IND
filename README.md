🇮🇳 FF IND — India Battle Royale

Explore India. Experience the adventure.

FF IND is an original India-inspired 3D browser game project designed with mobile players in mind.

🎮 Project Vision

Build an exciting, mobile-friendly 3D exploration and battle-royale-style game featuring recognizable Indian locations, regional environments, and original characters.

🗺️ Planned Indian Regions

- Mumbai, Maharashtra — Gateway of India, Marine Drive, CSMT and Bandra-Worli Sea Link.
- Delhi — India Gate, Red Fort, Qutub Minar and Lotus Temple.
- Agra, Uttar Pradesh — Taj Mahal and Agra Fort.
- Jaipur, Rajasthan — Hawa Mahal, Amber Fort and Jal Mahal.
- Kashmir — Dal Lake, houseboats and Himalayan scenery.
- Kerala — Munnar tea gardens and backwaters.
- Goa — Beaches and coastal villages.
- Punjab — Farms and traditional village environments.

🕹️ Planned Features

- 3D third-person gameplay.
- Mobile touch controls.
- Indian-inspired environments and landmarks.
- Day and night cycle.
- Character selection.
- Practice and exploration modes.
- Future multiplayer development.
- Android APK packaging.

🛠️ Technology

- Three.js
- HTML, CSS and JavaScript
- GitHub
- GitHub Pages
- ToApp for Android packaging

📱 Development Platform

Development is planned using an Android phone, with free and open-source tools wherever possible.

🚧 Development Status

Stage 1 — Initial prototype

The first goal is to create a small playable 3D environment with a player character, mobile controls and an Indian-inspired setting.
